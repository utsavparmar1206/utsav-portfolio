# Utsav Parmar — GitHub Portfolio

A lightweight, responsive static portfolio designed for **GitHub Pages**.

## Files

- `index.html` — website content
- `styles.css` — styling and responsive layout
- `script.js` — mobile navigation, reveal animations and image lightbox
- `assets/` — optimised portfolio images
- `Utsavkumar_Parmar_CV.pdf` — downloadable CV
- `.nojekyll` — tells GitHub Pages to serve the files directly

## Publish on GitHub Pages

This repository is ready to publish from the `main` branch and repository root using GitHub Pages.

## Updating later

Edit the text in `index.html`, replace assets with new images, or replace the CV PDF, then commit/push the changes. GitHub Pages republishes after your update.

## Privacy note

This version displays your email and LinkedIn profile. It does **not** display your phone number or visa information on the webpage.

## No paid services required

The site uses plain HTML, CSS and JavaScript. It has no paid theme, framework, database or server requirement.
